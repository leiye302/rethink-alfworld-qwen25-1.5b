# Idea

## Problem

Agent 在长程交互中可能沿着错误的推理继续行动，使局部错误逐步累积为任务失败。在以任务结果为主的训练中，整体反馈难以准确归因到具体决策，action 处的纠错信号较弱，模型难以学清楚何时应该放弃当前推理、如何调整下一步行动。我们希望让 Agent 在动作执行前自主发现并修正问题，将纠错内化为策略本身的能力。

---

## Limitation of Prior Work

Method A: 基于任务奖励的 Agent 强化学习

- 任务级奖励难以提供清晰的过程指导，关键推理与动作决策处的信用分配仍然困难。
- 优化任务成功并不直接等同于学会识别自身错误，缺少对纠错时机与纠错行为的显式学习。

Method B: 外部反馈驱动的反思与纠错方法

- 当纠错主要由外部裁判或固定规则触发时，模型自身判断何时需要纠错的能力缺乏直接训练。
- 依赖推理期反馈与多轮修订会增加调用成本和部署依赖，如何将这些指导内化为自主纠错能力仍是关键问题。

---

## Proposed Idea

我们提出 RETHINK，让 Agent 在 reasoning 结束、action 执行前自主判断是否需要纠错，并通过显式控制标记切换到纠正分支。

先通过监督学习建立纠错行为，再结合强化学习与自蒸馏，将任务级优化和自主触发步骤的局部指导结合起来，增强动作决策处的纠错信号。

额外指导仅在训练时使用，使模型学习“何时纠错”与“如何纠错”，在部署时独立完成推理、纠错与行动，而不依赖外部裁判。

---

## Expected Contribution

- **面向 Agent 的自主纠错框架**：将“何时纠错”与“如何纠错”统一纳入策略学习，使纠错从外部补救流程转变为模型可自主调用的决策能力。
- **面向动作决策的细粒度学习机制**：结合任务级优化与按需局部指导，增强关键决策位置的纠错信号，促进推理判断与实际行动的一致性。
- **跨 Agent 的统一纠错接口**：以 reasoning 与 action 的提交边界为接口，研究同一机制从环境交互到图像生成任务的迁移，探索可复用的 Agent 自主纠错范式。
